# 04. Żywa Oczyszczalnia

## Cel

Zamienić klasyczną przydomową oczyszczalnię w element systemu, który:
- oczyszcza ścieki,
- produkuje wodę możliwą do ponownego użycia w ogrodzie,
- dostarcza osad do kompostowania,
- integruje się z oranżerią i greywaterem,
- nie jest „czarną skrzynką”.

## Koncepcja

### Warstwy oczyszczania
1. **Osadnik / część biologiczna** – klasyczny zbiornik z osadem czynnym lub złożem biologicznym (podstawa legalna i skuteczna).
2. **Złoże roślinne (hydrobotaniczne)** – oczeret, pałka, irysy, wierzba energetyczna, trzcina, manna mielec itp.
3. **Strefa polerująca** – ewentualnie dodatkowy filtr piaskowy / żwirowy lub dalsze rośliny.
4. **Retencja i wykorzystanie** – woda trafia do ogrodu / food forestu / oranżerii (nie do wód powierzchniowych, jeśli przepisy pozwalają na wykorzystanie).

### Integracja z resztą systemu
- Greywater (prysznic, umywalki, pralka) może być prowadzony osobno lub częściowo łączony ze ściekami po odpowiednim potraktowaniu.
- Osad po stabilizacji → kompost / wermikompost (z zachowaniem zasad sanitarnych).
- Rośliny złoża mogą być częścią krajobrazu lub strefy buforowej przy oranżerii.
- Woda oczyszczona wspomaga nawadnianie w okresach suchych.

## Dual-use
- Oczyszczanie + produkcja biomasy (wierzba energetyczna / trawy)
- Oczyszczanie + element krajobrazu / biodiverystyczny
- Oczyszczanie + źródło wody do non-potable uses

## Rekomendacje praktyczne
- Zachować zgodność z przepisami (zgłoszenie / pozwolenie, norma PN-EN 12566 itp.).
- Lepiej zrobić solidną część biologiczną + dobre złoże roślinne niż próbować „cudownych” rozwiązań bez certyfikatów.
- Monitorować jakość odpływu (przynajmniej okresowo).
- Projektować z myślą o łatwym dostępie do serwisu (osadnik).

## Etapy wdrożenia
1. Audyt istniejącej oczyszczalni / szamba.
2. Decyzja: modernizacja vs nowa instalacja.
3. Projekt z uwzględnieniem złoża roślinnego i retencji.
4. Montaż + nasadzenia.
5. Monitoring i ewentualna korekta.
